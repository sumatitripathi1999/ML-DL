## 📌 Projects Included

### 1. 💼 Customer Churn Prediction
- **Objective**: Predict customer churn and identify key factors contributing to it.
- **Tech Stack**: Python, Scikit-learn
- **Model(s)**: Logistic Regression, Decision Tree, Random Forest
- **Result**: Achieved 78% accuracy with feature importance insights visualized in Power BI.

---

### 2. 💳 Credit Card Fraud Detection
- **Objective**: Detect fraudulent transactions in an imbalanced dataset.
- **Tech Stack**: Python, TensorFlow, Scikit-learn
- **Model(s)**: Anomaly Detection using Autoencoders
- **Result**: Achieved 90% accuracy and high precision.

### 3. 📈 Revenue Prediction
- **Objective**: Predict company revenue based on historical sales data.
- **Tech Stack**: Python, Scikit-learn, Pandas
- **Model(s)**: Linear Regression, Ridge, Lasso
- **Result**: R² score of 0.92 with optimized feature selection.

### 4. 💬 Sentiment Analysis (IMDB Reviews)
- **Objective**: Classify movie reviews as positive or negative.
- **Tech Stack**: Python, Keras, LSTM, Hugging Face
- **Model(s)**: LSTM-based RNN
- **Result**: 81% classification accuracy on the IMDB dataset.

### 5. 🛒 Market Basket Analysis
- **Objective**: Identify frequently bought itemsets and generate association rules.

### 6. ✈️ Flight Price Prediction
- **Objective**: Predict airline ticket prices using real-world features.
- **Tech Stack**: Python, Pandas, Regression Models
- **Model(s)**: Linear Regression, Random Forest Regressor
- **Result**: Achieved R² = 0.91 after feature engineering on airline, stops, and duration.
